App available at https://mutestreamingservice.ru/register.html
MuteStreamingService is an application that allows users to upload any music they like, listen to those tracks via an HLS player, add them to favorite/like lists, and track their listening history.
At the moment, the global version of the application is unavailable because I do not want to pay 200 rubles for a VPS to host it; however, users can deploy and use their own instances of the application.
For deploy your instance you will need: buy domain name and add A record for your VPS IP, VPS, install docker compose on VPS, pull repository, add config files, run `make build_exe` for build docker image and lauch go server, `docker compose up postgres nginx -d` for start nginx and postgreSQL, load postgres dump, then, navigate to your domain address and enjoy listening to music.
